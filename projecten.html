Projecten

Here are some of the projects I've worked on, showcasing my skills and creativity in various domains.

Quiz

Together with my classmates, I created an interactive quiz about traditional Polish food. It was our first group project, so we focused on teamwork and keeping the quiz fun and easy to use. The quiz introduces well‑known Polish dishes and tests the player’s knowledge in a simple, playful way. This project helped us improve our collaboration and basic web development skills.

Hoger Lager

I created this “Higher or Lower” game individually. The goal is simple: you guess whether the next number will be higher or lower than the current one. It’s an easy and fun game that tests your luck and quick thinking. This project helped me practice basic game logic, user interaction and clean JavaScript coding.

Mon-In

Mon‑In is a social platform I designed and built individually. It works similarly to LinkedIn: users can create their own profile, share posts, view other users, and build connections. The platform includes features like user authentication, profile pages, posting, and a dynamic feed. This project helped me improve my PHP, SQL, and front‑end skills while creating a real, functional social‑media experience.
